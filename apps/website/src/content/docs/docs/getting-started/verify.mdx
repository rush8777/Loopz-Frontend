# Verify your installation

Use a browser session you control and verify the installation in this order.

## Check the global API

After the page loads, open DevTools and evaluate:

```js
typeof window.analytics?.event;
```

It should return `"function"`. If it is `"undefined"`, first check the script URL, Content Security Policy, and browser network errors.

## Enable short-lived debug logging

```js
window.analytics.enableDebug();
window.analytics.event("movcues_install_verified");
```

Reload once and inspect the console plus the browser’s network panel. Remove or disable debug logging when the check is complete:

```js
window.analytics.disableDebug();
```

## Common outcomes

| Symptom | Likely cause | Next action |
| --- | --- | --- |
| `init() requires a siteId` | The script has no `data-site-id`, or manual `init()` is missing `siteId`. | Add the Site ID and reload. |
| API exists but no data appears | The Site ID is wrong, delivery is blocked, or Do Not Track is respected. | Check the active Site ID, network/CSP policy, and [privacy settings](/privacy/). |
| Two copies of the SDK | The loader was added to both an app shell and a page. | Keep one installation point. |

If the issue persists, use the diagnostic checklist in [Troubleshooting](/troubleshooting/).
