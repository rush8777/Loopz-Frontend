<p class="docs-label">Start here</p>

```html title="Install with one script"
<script
  async
  src="https://cdn.movcues.com/v1.js"
  data-site-id="YOUR_SITE_ID"
></script>
```

The loader exposes `window.analytics` and initializes itself from `data-site-id`. Use the [Quickstart](/docs/getting-started/quickstart/) for a complete, verifiable path.

## What the current release supports

Movcues automatically records page views, intentional interactive clicks, scroll milestones, and rage-click signals. You can also send custom events, identify users, define funnels, and launch configured experiences.

The SDK watches browser history, popstate, and hash changes for single-page applications. It does not need a framework-specific router integration for normal client-side navigation.

:::note
The documentation describes the shipped MVP1 runtime. Cursor movement, hover, element crawling, heatmaps, and session replay are deliberately disabled in this release—even if older README material mentions them. See [release availability](/docs/reference/availability/) before planning around an advanced collector.
:::
