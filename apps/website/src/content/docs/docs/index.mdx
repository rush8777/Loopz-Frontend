## Follow a complete journey

- [Launch your first experience](/docs/getting-started/first-experience/): connect your site, create a draft, preview, and publish.
- [Improve onboarding](/docs/guides/improve-activation/): inspect a funnel, save a drop-off audience, and target relevant guidance.
- [Introduce a feature](/docs/guides/feature-adoption/): find non-adopters and explain the next action in context.
- [Collect feedback](/docs/guides/collect-feedback/): ask after a real task and investigate the responses.

## Find an answer

Use search for a task, event, setting, or question. The sidebar separates dashboard operation from SDK implementation; existing developer article URLs remain available.

For a setup problem, start with [Connect and verify your site](/docs/getting-started/connect/). For missing activity, read [Missing data](/docs/help/missing-data/). For launch problems, read [Experience delivery](/docs/help/experience-delivery/).
