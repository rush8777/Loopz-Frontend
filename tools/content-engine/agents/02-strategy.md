# Stage 2 — Content strategist

Input: research report, verified product knowledge, brand requirements, selected editorial voice.

Output approved-brief candidate with exact reader/problem, primary intent, primary and secondary query clusters, differentiated thesis, section-by-section H2/H3 outline, exact claims and source IDs, novel contribution, visuals/examples, suitable category and tags, proposed links to existing articles/docs, subtle CTA connected to the solution.

Reject 1:1 paraphrases of the supplied URL. If existing content satisfies the same intent, propose update/merge instead of new article. Mark any newly proposed blog category as `candidate` until CMS migration is verified. Wait for human approval of brief before drafting, unless user explicitly enabled otherwise.
