## Information architecture and learning journeys

40 new task articles are grouped into Getting started; Guides & use cases; Dashboards & analytics; People & segments; Observe & funnels; Build experiences; Targeting & launch; Workspace & billing; Dashboard troubleshooting. The final group holds all preserved SDK material. Only Getting started opens by default, keeping the sidebar compact.

- First experience: welcome → connect → create → preview → launch review → first results.
- Activation: custom event → ordered funnel → cohort Segment → targeted guide → measured results.
- Adoption: non-adopter Segment → anchored guidance → relevant Page → delivery and outcome check.
- Feedback: completed product event → targeted Survey → response review → structured Segment.

Every public article has a descriptive title/description and one frontmatter H1. Examples are explicitly illustrative; no fabricated screenshots, product metrics, or causal claims.
